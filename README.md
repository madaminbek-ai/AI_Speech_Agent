# AI Speech Agent

Аудио → транскрипт со спикерами → бизнес-анализ → Google Sheets.
Шесть категорий из тестового задания, саммари, цель, результат и проверяемые цитаты.

## Бесплатный локальный режим (Linux)

OpenAI API не используется; автоматического перехода на платный API нет.
Для первого скачивания моделей нужен интернет. Аудио обрабатывается на компьютере;
при включенном экспорте отчет и полный транскрипт отправляются в Google Sheets.
Модели требуют нескольких GB диска и RAM; CPU работает медленнее GPU.
Базовая конфигурация: faster-whisper small, CPU int8, pyannote Community-1, Ollama qwen3:4b.
Модели речи загружаются последовательно и освобождаются до анализа текста.

### 1. Python-зависимости

Используйте Python, для которого доступны бинарные пакеты PyTorch, CTranslate2 и PyAV.
При ошибке `No matching distribution` создайте отдельное окружение Python 3.12.
Не удаляйте существующее окружение ради обновления.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
.venv/bin/python -m pip install -r requirements-local.txt
```

PyAV закреплен на 18.x: faster-whisper 1.2.1 несовместим с удаленным аргументом metadata_errors в PyAV 19.
PyAV в faster-whisper декодирует mp3 и другие форматы в 16 kHz mono.
В pyannote передается waveform в памяти. Предупреждение pyannote о встроенном
декодере torchcodec не мешает этому пути: вместо него используется PyAV. Отдельный системный ffmpeg в этом пути не вызывается.

### 2. Ollama

Можно установить Ollama только в папку проекта, без sudo:

```bash
bash scripts/install_ollama.sh
bash scripts/ollama.sh serve
```

В другом терминале:

```bash
bash scripts/ollama.sh pull qwen3:4b
```

Скрипты используют `.tools/ollama` и `.models/ollama` (исключены из Git).
Публичные модели Whisper сохраняются в `.models/whisper`.
Альтернатива: установите Ollama по официальной инструкции https://docs.ollama.com/linux.
Затем запустите сервер (если он еще не запущен как сервис):

```bash
ollama serve
```

В другом терминале:

```bash
ollama pull qwen3:4b
```

Модель должна быть локальной. OLLAMA_BASE_URL допускает только loopback-адрес.
Если RAM не хватает, можно скачать `qwen3:1.7b` и указать его в OLLAMA_MODEL;
качество бизнес-анализа нужно проверить отдельно. Закройте ресурсоемкие приложения.

### 3. Бесплатный доступ к спикерной модели

1. Создайте аккаунт Hugging Face.
2. Откройте https://huggingface.co/pyannote/speaker-diarization-community-1
   и самостоятельно примите условия доступа (CC-BY-4.0).
3. Создайте Read token: https://huggingface.co/settings/tokens.
4. Добавьте `HF_TOKEN=...` в `.env`. Не отправляйте токен в чат и не коммитьте его.

JSON service account Google и HF_TOKEN — разные учетные данные.
Доступ к gated-модели нельзя получить одним лишь добавлением токена без принятия условий.

### 4. Настройка и запуск

Если `.env` уже настроен для Sheets, сохраните его и добавьте недостающие параметры
из `.env.example`. Для нового проекта скопируйте `.env.example` в `.env`.

```dotenv
AI_BACKEND=local
WHISPER_MODEL=small
WHISPER_LANGUAGE=
HF_TOKEN=your_huggingface_read_token
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen3:4b
```

Пустой WHISPER_LANGUAGE включает автоопределение. Для одноязычных записей можно задать
`uz` или `ru`. Смешанную речь и качество small необходимо оценивать на реальных звонках.

```bash
.venv/bin/python -m streamlit run app.py
```

Выберите «Бесплатно на компьютере», нажмите «Проверить локальную настройку»,
загрузите аудио и нажмите «Анализировать». Проверка настройки не скачивает gated-модель;
доступ к ней проверяется при первом анализе. Не запускайте `python app.py`.
После изменения `.env` перезапустите Streamlit.

## Google Sheets

1. Включите Google Sheets API в Google Cloud.
2. Сохраните исходный JSON service account как `service_account.json` рядом с app.py.
3. Создайте пустую Google Spreadsheet; запишите ее ID в GOOGLE_SHEET_ID в `.env`.
4. Поделитесь таблицей с `client_email` из JSON с правами редактора.
5. В интерфейсе включите автоматическую отправку или отправьте готовый отчет отдельной кнопкой.

Программа создает вкладку Calls и с помощью RAW добавляет строки.
Существующий лист Calls с другой структурой отклоняется без изменения данных.
Относительный GOOGLE_SERVICE_ACCOUNT_FILE разрешается относительно папки проекта.

Проверка подключения без обращения к AI (создает вкладку/заголовки):

```bash
.venv/bin/python -c 'from dotenv import load_dotenv; from sheets import google_worksheet; load_dotenv(".env"); ws = google_worksheet(); print("Connected:", ws.title)'
```

## Дополнительный платный режим

Существующая интеграция OpenAI сохранена. Выберите OpenAI в интерфейсе и задайте
действующий OPENAI_API_KEY с оплаченным API-балансом. При ошибке локального режима
переключение на платный режим не происходит. Модели и параметры API нужно проверять
по актуальной документации провайдера.

## Поведение и ограничения

- Не больше 25 MiB на файл; локально до 1800 секунд и 16000 символов транскрипта.
  Длинный текст отклоняется явно, не обрезается. Лимиты задаются LOCAL_MAX_AUDIO_SECONDS,
  LOCAL_MAX_TRANSCRIPT_CHARS и OLLAMA_NUM_CTX; увеличение требует дополнительной памяти.
- Спикер определяется по максимальному суммарному пересечению времени слова с результатом
  pyannote. Без надежного пересечения выводится UNKNOWN, а роль остается «Неизвестно».
  Это не биометрическая идентификация. Смена ролей и перекрытия могут давать ошибки.
- Текст отчета русский; оригинальный язык реплик сохраняется. Точность не гарантирована.
  Нужен размеченный набор звонков для оценки. Самооценка confidence не является метрикой.
- Пустые/несовпавшие цитаты удаляются; отсутствие проверяемых цитат снижает уверенность.
- Результаты и транскрипты сохраняются в session_state, поэтому не исчезают при переключении
  checkbox. Это не постоянная БД: закрытие/перезагрузка вкладки может сбросить историю.
- Повтор одинакового файла в одной пачке пропускается. Повтор в текущей сессии использует
  готовый отчет при тех же настройках. Ошибку Sheets можно повторить без нового AI-анализа.
- Sheets дедуплицируется по Call ID; конкурентные записи не защищены транзакцией.
  Повторный анализ другой моделью не заменяет уже существующую строку.
- Экспорт CSV экранирует обычные формульные префиксы, но повторное сохранение CSV в табличном
  редакторе может изменить интерпретацию. JSON сохраняет исходные строковые значения.
- .env и service_account.json — секретные файлы. Не коммитьте и не отправляйте их.

## Проверки

```bash
.venv/bin/python -m pytest -q
```

Unit-тесты мокируют модели и HTTP; они не скачивают веса, не отправляют аудио
и не заменяют проверку на реальных записях и реальном Google Sheets.
